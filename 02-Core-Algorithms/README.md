# 02 · Core Algorithms

The bulk of ECPC. A team solid on everything here, and fast at typing it,
qualifies.

Lessons are listed in [`../CURRICULUM.md`](../CURRICULUM.md) and will be
written as the training plan reaches them — weeks 4–26 of
[`../TRAINING-PLAN.md`](../TRAINING-PLAN.md).

The rule for this tier: **every data structure is implemented from scratch
once, and stress-tested, before it is used.** A DSU you copied is a DSU you
cannot debug when it is 40 minutes into a contest and the answer is off by one.
